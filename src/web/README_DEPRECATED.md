# DEPRECATED: Python FastAPI Web Backend Removed

## Status

The Python FastAPI/Celery backend has been **completely replaced** with a Rust-based backend (weissman-server).

## What Happened

- **Old**: Python FastAPI app with Jinja2 templates (`src/web/templates/`) and static assets (`src/web/static/`)
- **New**: Rust Axum server serving React frontend from `frontend/dist/`

## Directories in This Location

- `templates/` - **DEPRECATED**: 28 HTML templates for the old Python backend (login, dashboard, reports, etc.)
- `static/` - **DEPRECATED**: CSS and JavaScript files for the old Python backend

## Why Are They Still Here?

These directories are kept temporarily for reference during the migration period. They contain:

1. UI/UX patterns that may inform React component design
2. Template logic that might need to be ported to frontend
3. Static assets that might be reused

## What To Use Instead

### For the Web UI:
- **Frontend**: `/frontend` (React + Vite)
- **Backend API**: `/backend/weissman-server` (Rust Axum)
- **Command Center**: Access at `http://localhost:8000/command-center/`

### Running the Stack:
```bash
# Start Rust backend
cargo run -p weissman-server

# Or using Docker
docker-compose up
```

## Cleanup Plan

These directories will be removed once:
1. All UI functionality has been verified in the React frontend
2. All static assets have been migrated or confirmed unnecessary
3. Documentation has been fully updated

## Migration Notes

If you need to extract information from these templates:

1. **Authentication UI**: Now handled by Rust backend JWT + React forms
2. **Dashboard**: React components in `/frontend/src/pages/`
3. **Reports**: Generated by Rust backend, rendered in React
4. **Scan Results**: WebSocket + React components
