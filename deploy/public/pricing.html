Frequently asked questions

Is anything ever simulated?

No. Every production engine hits a real endpoint or host surface, parses real evidence, and only fires on observed behavior. Engines that need on-host visibility are marked agent_required and show an empty state until your endpoint agent is online.

Can I run this offline / air-gapped?

Yes. Self-hosted ships as Docker Compose or systemd binaries + Postgres + Redis + optional Ollama. Threat-intel feeds can be mirrored locally.

What about my LLM bill?

Self-hosted: point at Ollama / vLLM / OpenAI and pay your provider. Cloud: AI features (Council, Ask Weissman) require WEISSMAN_LLM_BASE_URL — configure per deployment.

Will Weissman scan things I didn't authorise?

Never. Every scan target is validated against the client's approved scope. Out-of-scope probes are rejected at the API edge with 403, before a packet leaves the network.
