How it works

Four steps. Zero ceremony.

1

Onboard a target

Add a client + scope (domains, IP ranges, AWS role ARN). Scan-scope enforcement blocks any out-of-bounds probe automatically.

2

Continuous scanning

Orchestrator runs configured engines on a tenant-defined cadence. Findings are deduplicated by stable signature, re-firings bump seen_count.

3

Triage & verify

Drawer with full evidence, MITRE link, CVE link, remediation steps, compliance impact (ISO27001 / SOC2 / PCI). Mark FP → engine learns.

4

Auto-fix or alert

Critical + verified findings open a PR (or fire a Slack/Teams webhook + SMTP). Patch is sandbox-verified before merge.
